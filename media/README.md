# Media

Add demo media of the clock in operation here.

## Demo Video

Record a short video showing:
1. A Lightning payment being sent (QR code scan or `./test_payment.sh 21`)
2. The cuckoo clock chiming in response
3. Music playing on the Bluetooth speaker simultaneously

**Recommended filename:** `demo.mp4`

Once recorded, either:
- **Add to this folder** and commit (keep under ~100MB or use Git LFS)
- **Upload to YouTube** and embed in the main README:
  ```markdown
  [![TIMECHAIN Demo](https://img.youtube.com/vi/VIDEO_ID/0.jpg)](https://www.youtube.com/watch?v=VIDEO_ID)
  ```

## Screenshots

Screenshots of the QR donation page, the LNbits wallet UI, or the payment flow
are also welcome here.

Suggested filenames:
- `qr-page.png` — the fullscreen QR donation page at `http://localhost:8000/qr`
- `lnbits-wallet.png` — the LNbits wallet showing incoming payments
- `payment-flow.png` — diagram of the full payment → chime flow
